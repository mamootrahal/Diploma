# Diploma

Выпускная квалификационная работа (LaTeX, ГОСТ 7.32-2017).

## Сборка

```bash
latexmk          # собрать build/main.pdf
latexmk -pvc     # пересобирать автоматически при изменениях
latexmk -c       # удалить временные файлы
```

В VS Code с расширением LaTeX Workshop PDF собирается при сохранении (Ctrl+Alt+V — открыть просмотр).

## Структура

- `main.tex` — главный файл, порядок частей
- `gost.sty` — оформление (поля, шрифт, заголовки, подписи)
- `title.tex` — титульный лист
- `chapters/` — введение, главы, заключение, приложения
- `bibliography.bib` — источники
- `images/` — рисунки
